How to use the Kinship Chart Creator

Adding people

Add a person
Drag a symbol from the People palette onto the canvas. It snaps to the grid. Triangle = male, circle = female, square = unknown sex.
Name a person
Double-click a symbol and type their name.
Deceased
Right-click a person → Add deceased slash (a diagonal line through the symbol).
Default shape color
Right-click a symbol in the palette to set a default fill for every new person of that type.

Relationships

Using the buttons
Click a relationship (or press M marriage, P partnership), then click the two people. For Parent → child, click the couple's union line (or a single parent), then the child.
Shift-drag to connect
Shift+drag one person onto another = marriage. Shift+drag a union line onto a person = child.
Shift-drag to empty
Shift+drag to blank space and pick a shape — it's created there and connected (spouse from a person, child from a union line).
Divorce / separation
Right-click a marriage line → Add divorce slash, or a partnership line → Add separation slash (useful for former partners shown only to establish a child's parentage).
Delete a link
Right-click any line → Delete link.

Selecting & moving

Select
Left-click a person or line. Shift+click adds/removes a person from the selection.
Box-select
Left-drag across empty space to select everyone inside the box.
Move
Drag a selected person; a multi-selection moves together. Connector lines follow.
Delete
Press Delete / Backspace. Esc cancels linking or clears the selection.

Colors & legend

Define colors
In the Colors panel, add color + label rows. The × removes one (it asks first if that color is in use).
Apply a color
Select one or more people, then click a swatch in the Selected panel — or right-click a person and choose a color.
Legend
Turn on Legend in PNG to include a key in the export. It lists only the symbols, lines, and colors you actually used.

Navigating the canvas

Pan
Right-click and drag on empty space.
Zoom
Scroll wheel (zooms toward the cursor).
Center / Fit
Space centers the view on your chart; Enter zooms to fit everything.

Saving & exporting

Keep editing later
Save JSON downloads the whole chart; Load JSON restores it (colors and defaults included).
Export image
Export PNG saves a high-resolution image cropped to your chart, with the legend if enabled.
